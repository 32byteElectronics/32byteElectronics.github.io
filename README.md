# Byte Electronics Website

Static GitHub Pages website for Byte Electronics.

## Recommended GitHub Pages setup

1. Create a GitHub repository named `32byteElectronics.github.io`.
2. Upload all files and folders from this package to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. The website should become available at:
   `https://32byteElectronics.github.io/`
5. Open Google Search Console and add the website as a URL-prefix property.
6. Verify ownership. If using the HTML tag method, replace
   `REPLACE_WITH_GOOGLE_SEARCH_CONSOLE_TOKEN` in `index.html` with the token supplied by Search Console, commit the change, then complete verification.
7. Use the verified website when Google asks for the organization website during Android Developer Console registration.
